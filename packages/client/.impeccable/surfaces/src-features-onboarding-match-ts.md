# Contextual guidance

Operate surface extending Graphite Command Stations. The battlefield remains
primary: Important is the provisional default, each hint appears once per local
browser profile, and only one brief hint appears with More and Dismiss. The
optional original help icon labels active HUD regions; individual command
tooltips retain names and current shortcuts. No empty selection station appears.

Guidance uses the existing native Settings panel for staged All/Important/Off
and history reset, with Apply/Back and explicit storage failure. Match links
reuse the paused native menu and installed manual entry. No separate game-state
owner, modal teaching flow, new raster or visual identity is introduced.

Manual concept/control pages remain Read surfaces within the shared gallery.
They explain implemented mechanics, while actor facts remain compiled content
and the controls page uses the current binding profile. Desktop uses the existing
list/detail split; narrow layouts stack and scroll. The signature interaction is
moving from a real observed event or selected actor directly to its reference
while retaining the paused match. No decorative motion is added.
