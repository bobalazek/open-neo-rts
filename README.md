# Open Neo RTS

Open Neo RTS is an open-source real-time strategy game inspired by a couple of classinc RTS games that I played in my childhood. The game is under active development and is not yet playable. Over the next couple of weeks, I will be adding mainly ideas and feature I may want to implement in the game and once I feel it's ready, I (or, you know, Claude/Codex) will start with the implementation.
