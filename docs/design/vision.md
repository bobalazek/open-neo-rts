# Vision

## What

An open-source, browser-first 3D real-time strategy game, moddable from the start, with a Tauri desktop app alongside the web version.

We are building **a game**, not a generic RTS engine. The underlying systems are reusable, so others can build factions, maps, modes and whole game packs on top of it.

> **Foundational rule:** build a game that's fun to play, then make its engine reusable.

## Feel

- Direct combat and base building, readable units, fast matches.
- A blocky, toy-brick look: armies, buildings and terrain built from chunky bricks and voxels, bright faction colours, and units that read clearly at RTS zoom.
- Optional grand-strategy depth (territory, cities, eras, wonders, trade) as rule modules a match can switch on, never forced into every game.

## What makes it distinct

1. **Shared and cooperative command.** Several humans can command one army, diplomacy is configurable, and defeated players can rejoin an ally. See [multiplayer.md](multiplayer.md).
2. **Battlefield salvage.** Wrecks are an economic and tactical resource.
3. **Open content.** Factions, units, abilities, maps and game modes are declarative, validated data that players create and share.
