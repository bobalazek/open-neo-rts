# Roadmap

Build only what the current phase lists. The design and engineering docs describe the whole game; this page says what's in scope when. Concrete work items are in [tasks.md](./tasks.md); blockers on people are in [human-tasks.md](./human-tasks.md).

## Phases

| Phase                      | Deliverable                                                                                                                                                                         | Rough effort*          |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| 0. Design and foundations  | Docs, monorepo, tooling, CI, content model and validators, faction definitions                                                                                                      | finishing              |
| 1. Technical foundation    | **1a:** deterministic headless simulation. **1b:** renderer, camera, terrain, selection, movement, pathfinding                                                                      | 2–4 weeks              |
| 2. First playable          | Local skirmish: an Eastern Collective mirror match against a bot, with base building by builders, economy, combat and victory                                                       | 1–3 months             |
| 3. Vertical slice          | The Eastern Collective's full roster polished, real art for it, plus the first online play: 1v1 and 2v2 Shared Command through the match server                                     | 2–4 months             |
| 4. Expansion               | The Alliance of Free Nations and the Phoenix Initiative complete, air and naval, upgrades, neutrals and wonders, map editor, objectives and triggers, Basic Training, campaign core | Several months         |
| 5. Multiplayer and release | Room browser, voice, diplomacy, accounts and ranked play, Tauri desktop, release pipeline                                                                                           | Several months or more |

\*Very approximate elapsed time for one experienced developer working consistently. Not commitments.

**Multiplayer timing:** determinism and the per-seat visibility projection exist from phase 1. Single player runs the sim in a Web Worker behind the same projection, so fog and protocol bugs show up offline in phase 2. Online play arrives in phase 3, deliberately small, to prove the server-authoritative design before the content grows.

## Exit criteria

| Phase  | Done when                                                                                                                                                                                                                                                                   |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **0**  | Every faction's units and structures validate against the current schema with zero errors; the docs have no stale references; decisions are recorded                                                                                                                        |
| **1a** | `bun neo run` plays a scripted 2-Force scenario for 10,000 ticks. Checkpoint hashes are identical across two runs in one process, two processes, and Chromium, Firefox and WebKit. `packages/deterministic` has golden tests for every function. CI runs all of this        |
| **1b** | 200 units move and path on a 128×128 map with height levels at 60 fps (medium preset). Selection, box select, move and attack-move work. The renderer reads only the projection                                                                                             |
| **2**  | A human beats or loses to the first bot in an Eastern Collective mirror on Training Grounds, by Last Man Standing, in 10–25 minutes. Every tier-1 Collective unit and structure is used. The replay reproduces the final hash. No crash in 20 AI-vs-AI matches across seeds |
| **3**  | Two people finish a 1v1 online, and two people share one Force in a 2v2 against bots, with reconnect working. Fog-leak tests pass on every message type. The Eastern Collective plays a full match with real models                                                         |
| **4**  | Three factions with win rates of 45–55% in AI-vs-AI runs. A map made in the editor plays online. A Wonder Race finishes. Basic Training is completable                                                                                                                      |
| **5**  | Public release: browser and desktop builds, stable and beta channels, rollback tested                                                                                                                                                                                       |

## Gate after phase 1

If controlling a group of tanks around a simple map already feels enjoyable, continue. If not, fix the feel before adding anything else.
