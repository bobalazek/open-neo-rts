# 2026-11-04 — Original and CC0 audio are allowed

**Context.** The owner explicitly broadened the original-assets rule for audio:
"can prepare own audio, but can also use some cc0 assets".

**Decision.** Audio can be authored for the project or sourced under a verified
CC0 dedication. This exception applies to sounds and music; it does not change
the original-work rule for models, icons or textures. Use whichever fits the game
and helps complete the playable audio library. The six first combat clips remain
original synthesis; no imported clip is included by this policy change alone.

For an imported clip, verify the creator's own download page and accompanying
license evidence, preserve both with the original filename/source bytes, and
record processing needed to produce the runtime Ogg. Keep only used clips in the
repository and retain their CC0 status. `assets.json` must name the actual creator,
not the owner or the importing agent. The existing agent-made-asset credit rule
continues to apply to newly authored project assets.

**Next source candidates.** Kenney's official
[Impact Sounds](https://kenney.nl/assets/impact-sounds) and
[Digital Audio](https://kenney.nl/assets/digital-audio) pages identify those packs
as Creative Commons CC0. They are candidates for later imports, not evidence that
any particular clip is already shipped or fits the mix. Check the downloaded
license and selected clip before importing. The format, loudness, spatial/fog,
provenance and Git LFS requirements remain unchanged.
