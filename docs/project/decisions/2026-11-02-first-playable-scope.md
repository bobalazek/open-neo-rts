# 2026-11-02 — Use the existing Eastern Collective tier 1 provisionally

**Context.** Implementing the first working skirmish needs a roster and starting
balance. Existing authored definitions and first-pass artwork are available.

**Decision.** The owner approved the existing Eastern Collective tier-1 roster
and authored numbers as provisional balance for a mirror match on Training
Grounds. Use the roadmap's Last Man Standing objective and the existing starting
kit. Tune these values after the gameplay loop works.

The tier-1 inventory is Command Center, Industrial Reactor, Supply Depot,
Barracks Complex, War Factory, Fortress Wall and Anti-Air Complex; Field
Technician, Collective Soldier, Rocket Trooper, Drone Hunter, Supply Truck,
Dragon Tank and Metamorphic APC. Preserve their documented features and flag
missing values rather than inventing defaults.

**Consequences.** The first-playable scope and existing tier-1 numbers no longer
block implementation. This approval does not approve new numbers where content
has none, resolve conflicting construction/targeting rules or sign off all
faction additions. Those decisions remain in human tasks.
