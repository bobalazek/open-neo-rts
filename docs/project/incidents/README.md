# Incidents

One post-mortem per outage, data loss, security problem or broken release, once anything is running. Append-only.

File names: `YYYY-MM-DD-short-slug.md`. Add one line to the index for each.

```markdown
# YYYY-MM-DD — Short title

**What happened.** Timeline with times.

**Impact.** Who was affected and how.

**Cause.** The root cause, not the trigger.

**Fix.** What was done, and what prevents a repeat.
```
