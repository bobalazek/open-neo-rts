# Content

Game data: JSON definitions with their assets, grouped in packs. No code. The format, IDs and every field: [content-format.md](../docs/contributing/content-format.md).

```text
content/
├── schemas/                        JSON schemas generated by `bun neo generate-schemas` (never edited by hand)
└── core/                           the base game
    ├── manifest.json               lists every definition file
    ├── factions/
    │   ├── alliance-of-free-nations/
    │   ├── eastern-collective/
    │   └── phoenix-initiative/     each: faction.json, units/<name>/, structures/<name>/
    └── maps/
        └── training-grounds/
```

Add content: [adding-content.md](../docs/contributing/adding-content.md). Assets: [assets.md](../docs/contributing/assets.md). Check everything with `bun neo validate`.
